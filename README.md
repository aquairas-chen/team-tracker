# 团队进度追踪（Team Progress Tracker）

> 零成本、全加密、微信可用的团队项目追踪工具。
> 线上地址：https://aquairas-chen.github.io/team-tracker/ （需访问密码）

## 这是什么

一个**单 HTML 文件**构成的团队协同追踪应用：甘特图 + 依赖关系图 + 任务列表 + 里程碑 + 成员协作 + 微信每日提醒。无需购买任何服务器或数据库——GitHub Pages 托管页面，GitHub 仓库当数据库，GitHub Actions 当定时器，Server酱 当微信通道，**全部免费**。

## 功能全景

| 模块 | 能力 |
|---|---|
| 甘特图 | 双日期轴、今日线、里程碑线、依赖连线、滚轮/双指缩放、拖拽改期、基线对比（幽灵条）、导出 PNG（带当天日期戳） |
| 依赖图 | 自动分层、关键路径、节点上下游高亮、缩放 |
| 任务列表 | 8 大类型域配色、优先级 P0/P1/P2、预估工时、状态筛选、桌面双列 |
| 里程碑 | 倒计时卡、时间线、硬节点标识 |
| 我的 | 我的任务、我处置过的、我的动态 |
| 反复思考 | 备忘录（新增/删除，全团队可见） |
| 协作反馈 | 成员选身份、🔄进行中、✅完成、⚠️预警（填原因）、已读回执、2 分钟轮询同步 |
| 预警闭环 | 管理员「处理并回复」，成员可见处理结果与回复 |
| 任务动态 | 进度/完成/预警/改期/评论全程留痕（最近 300 条，防并发合并） |
| 讨论区 | 每个任务支持评论 + 附件（≤1.5MB，图片直显，存私有仓库） |
| 自动进度 | 「进行中」任务按时间基准自动爬升（斜纹显示），手动改高不会被拉低，可在设置关闭 |
| 提醒 | 未启动 / 临期(≤3天且<50%) / 已延期 / 停滞(3天无动态) 四类，红点角标 |
| 微信推送 | 每天 21:17（北京时间）管理员收全量清单；成员配 SendKey 后收个人清单 |
| 基线与版本 | 一键保存基线；每次发布自动快照（保留 30 个），可一键回滚 |
| 响应式 | 手机 / iPad / 桌面三档布局 |

## 架构

```
┌─ 主仓库 team-tracker（公开，但零明文）──────────────┐
│  index.html          单文件应用（无构建、无依赖）     │
│  data.enc            计划数据（AES-256-GCM 加密）     │
│  scripts/remind.mjs  每日提醒脚本                    │
│  .github/workflows   cron 21:17 北京时间触发         │
└──────────────────────────────────────────────┘
┌─ 反馈仓库 team-tracker-feedback（私有）─────────────┐
│  m_<成员>.json   完成/进行中/预警/已读（每人一文件）   │
│  control.json    管理员处置（预警回复/撤销完成）       │
│  activity.json   任务动态留痕                        │
│  comments.json   任务评论                            │
│  memos.json      反复思考备忘录                      │
│  att/            评论附件                            │
│  snap/           版本快照（自动，留 30 个）           │
└──────────────────────────────────────────────┘
```

## 安全模型

- 计划数据在**公开仓库中以密文存放**：AES-256-GCM，密钥由访问密码经 PBKDF2（150,000 次迭代，SHA-256）派生，全部在浏览器内完成，密码永不上传。
- 成员写操作走 **fine-grained PAT**，仅授权反馈仓库 contents 读写，且该令牌本身也加密存放在 data.enc 内。
- 管理员发布走管理员个人令牌，**只保存在管理员本机浏览器** localStorage，不进任何仓库。
- 本仓库（含 README）不含任何真实密钥。

## 日常运维

- **改计划**：页面 → 🔒管理（输入管理员令牌）→ 增改任务/拖拽改期 → 🚀发布。成员 1-3 分钟自动收到。
- **回滚**：管理模式 → ⚙️设置 → 历史版本 → 回滚到此版本。
- **每日推送**：GitHub Actions `daily-wechat-remind`，cron `17 13 * * *`（UTC）= 北京 21:17，可手动 Run workflow。
- ** secrets**：`VIEW_PW`（访问密码）、`SCT_KEY`（管理员 Server酱 SendKey），在仓库 Settings → Secrets 维护。
